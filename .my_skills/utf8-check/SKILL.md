# UTF-8 Check (Проверка UTF-8 кодировки)

**Когда использовать:** ПЕРЕД сохранением любых правок в HTML/JS файлах — после `edit()`, перед тестированием.

**Цель:** Предотвратить повреждение кодировки — кракозябры, потеря русских символов, нечитаемые строки.

---

## Пошаговая инструкция

### 1. ПЕРЕД сохранением правок
- [ ] Проверить, что файл сохраняется в UTF-8 (автоматически в `write_file`)
- [ ] Если используется PowerShell → добавить `-Encoding UTF8`
- [ ] Если используется Node.js → указать `'utf8'` в `writeFileSync`

### 2. ПОСЛЕ сохранения
- [ ] Проверить последние 10 строк на закрывающие теги:
  ```powershell
  $lastLines = Get-Content 'файл.html' -Tail 10
  $lastLines | ForEach-Object { Write-Host $_ }
  ```
- [ ] Ожидается: `</script>`, `</body>`, `</html>`
- [ ] Если видны кракозябры → файл повреждён, восстановить из копии

### 3. ПРОВЕРКА целостности
- [ ] Посчитать строки (`Measure-Object -Line`)
- [ ] Проверить баланс `{}` скобок
- [ ] Если строки меньше ожидаемого → файл усечён

### 4. ЕСЛИ файл повреждён
- [ ] НЕ применять следующие правки
- [ ] Восстановить из резервной копии
- [ ] Проверить целостность восстановленного файла
- [ ] ТОЛЬКО ПОСЛЕ проверки → применять правки

---

## Правила пользователя

1. **ВСЕГДА проверять UTF-8** — особенно после PowerShell команд
2. **Последние 10 строк** — должны быть закрывающие теги `</script></body></html>`
3. **Кракозябры = повреждение** — НЕ продолжать, восстановить из копии
4. **PowerShell с UTF-8** — всегда добавлять `-Encoding UTF8`
5. **Node.js с utf8** — всегда указывать `'utf8'` в `writeFileSync`

## Плохой пример

### ❌ Пример: Повреждение UTF-8 без проверки (2026-11-03)

**Задача:** Добавить функцию `_resetAccountInternal()`

**Что сделано НЕПРАВИЛЬНО:**
1. ❌ НЕ проверена UTF-8 кодировка ПОСЛЕ правки
2. ❌ НЕ проверены последние 10 строк
3. ❌ Файл усечён до 443 строк
4. ❌ Видны кракозябры в конце файла

**Симптом:** `Uncaught SyntaxError: Unexpected end of input`

**Причина:** PowerShell команда без `-Encoding UTF8` повредила файл

**Как исправить:**
- ВСЕГДА проверять UTF-8 ПОСЛЕ правок
- Проверять последние 10 строк на закрывающие теги
- Если видны кракозябры → НЕ продолжать, восстановить из копии

## Шаблоны

### Шаблон проверки UTF-8
```powershell
# PowerShell
$lastLines = Get-Content 'my_strategy_025.html' -Tail 10
$lastLines | ForEach-Object { Write-Host $_ }

# Ожидается:
# </script>
# </body>
# </html>
```

### Шаблон проверки целостности
```powershell
# PowerShell
$c = Get-Content 'my_strategy_025.html' -Raw
$o = ([char[]]$c | Where-Object {$_ -eq '{'}).Count
$cl = ([char[]]$c | Where-Object {$_ -eq '}'}).Count
$lines = (Get-Content 'my_strategy_025.html' | Measure-Object -Line).Lines
Write-Host "Строк: $lines | {: $o | }: $cl | Баланс: $(if($o -eq $cl){'✅'}else{'❌'})"
```
