# Backup First (Резервная копия ПЕРЕД правками)

**Когда использовать:** ПЕРЕД любыми правками HTML/JS файлов — добавление функций, кнопок UI, исправление багов, рефакторинг.

**Цель:** Предотвратить потерю данных при повреждении файла — всегда иметь рабочую резервную копию.

**КРИТИЧЕСКИ ВАЖНО:** НИКОГДА не затирать восстановленную версию рабочей копией с ошибками.

---

## Пошаговая инструкция

### 1. ПЕРЕД правками
- [ ] Создать резервную копию файла:
  ```powershell
  # PowerShell
  Copy-Item 'my_strategy_025.html' 'my_strategy_025.html.bak_20261117'
  ```
- [ ] Проверить целостность копии (строки, скобки, UTF-8):
  ```powershell
  $c = Get-Content 'my_strategy_025.html.bak_20261117' -Raw
  $o = ([char[]]$c | Where-Object {$_ -eq '{'}).Count
  $cl = ([char[]]$c | Where-Object {$_ -eq '}'}).Count
  $lines = (Get-Content 'my_strategy_025.html.bak_20261117' | Measure-Object -Line).Lines
  Write-Host "КОПИЯ: Строк: $lines | {: $o | }: $cl | Баланс: $(if($o -eq $cl){'✅'}else{'❌'})"
  
  # Проверка UTF-8 (последние 10 строк)
  $lastLines = Get-Content 'my_strategy_025.html.bak_20261117' -Tail 10
  if ($lastLines -notmatch '</script>' -or $lastLines -notmatch '</body>' -or $lastLines -notmatch '</html>') {
      Write-Host "❌ Отсутствуют закрывающие теги!"
  }
  ```
- [ ] Убедиться, что копия НЕ усечена (последние 10 строк — `</script></body></html>`)

### 2. ЕСЛИ файл уже повреждён
- [ ] НЕ применять правки
- [ ] Сообщить пользователю: «Файл повреждён (строка X, баланс {}: Y/Z). Восстановите из резервной копии.»
- [ ] Ждать подтверждения восстановления

### 3. ПОСЛЕ восстановления из резервной копии
- [ ] НЕ затирать восстановленную версию рабочей копией
- [ ] Проверить целостность восстановленного файла
- [ ] ТОЛЬКО ПОСЛЕ проверки применять правки

### 4. ПОСЛЕ всех правок
- [ ] Создать рабочую резервную копию (с датой и версией):
  ```powershell
  Copy-Item 'my_strategy_025.html' 'my_strategy_025_v0.25_20261117.html'
  ```
- [ ] Проверить целостность рабочей копии

---

## Правила пользователя

1. **ВСЕГДА создавать копию ПЕРЕД правками** — даже для минимальных изменений
2. **Проверять целостность копии** — баланс `{}`, последние 10 строк
3. **НИКОГДА не затирать восстановленную версию** — пользователь восстанавливает ЛИЧНО
4. **Имя копии** — включать дату (YYYYMMDD) и версию (если есть)
5. **Хранить 3 последние копии** — удалять старые при создании новой
6. **UTF-8 проверка** — проверять последние 10 строк на закрывающие теги `</script></body></html>`

## Хорошие примеры

### ✅ Пример 1: Резервная копия перед исправлением таймера (2026-11-17)

**Задача:** Исправить таймер — использовать `startTime` вместо `lastBarTime`

**Действия:**
1. ПЕРЕД правками:
   ```powershell
   Copy-Item 'my_strategy_025.html' 'my_strategy_025.html.bak_20261117'
   ```
2. Проверка копии:
   ```
   КОПИЯ: Строк: 3450 | {: 1201 | }: 1201 | Баланс: ✅
   ```
3. Применение правки: `edit()` → замена функции `update()`
4. Проверка после правки:
   ```
   Строк: 3199 | {: 1198 | }: 1198 | Баланс: ✅
   ```

**Результат:** Файл целостен, резервная копия сохранена.

### ✅ Пример 2: Восстановление из резервной копии (2026-11-03)

**Ситуация:** Файл усечён до 443 строк (обрывается на `boot();`)

**Действия:**
1. Обнаружение усечения:

   ```
   Строк: 443 (ожидалось 456)
   ```

5. ТОЛЬКО ПОСЛЕ проверки → применение правок

**Результат:** Файл восстановлен, правки применены без ошибок.

## Плохой пример

### ❌ Пример: Усечение файла без резервной копии (2026-11-03)

**Задача:** Добавить функцию `_resetAccountInternal()`

**Что сделано НЕПРАВИЛЬНО:**
1. ❌ НЕ создана резервная копия ПЕРЕД правками
2. ❌ `edit()` нашёл 2 вхождения `old_string` → выбрал первое (строка 1287)
3. ❌ ПОСЛЕ правки файл усечён до 443 строк
4. ❌ НЕ проверены последние 10 строк на закрывающие теги
5. ❌ Пользователь спросил: «Ты случайно не затёр мою восстановленную версию?»

**Симптом:** `Uncaught SyntaxError: Unexpected end of input`

**Причина:** `old_string` содержал незакрытую `{` → `edit()` вставил правку, но файл усёкся

**Как исправить:**
- ВСЕГДА создавать копию ПЕРЕД `edit()`
- Проверять баланс `{}` в `old_string`
- ПОСЛЕ правки: проверить последние 10 строк
- Если файл усечён → НЕ применять следующие правки, сообщить пользователю

## Шаблоны

### Шаблон создания резервной копии
```powershell
# PowerShell
$timestamp = Get-Date -Format 'yyyyMMdd_HHmmss'
Copy-Item 'my_strategy_025.html' "my_strategy_025.html.bak_$timestamp"

# Проверка целостности
$c = Get-Content "my_strategy_025.html.bak_$timestamp" -Raw
$o = ([char[]]$c | Where-Object {$_ -eq '{'}).Count
$cl = ([char[]]$c | Where-Object {$_ -eq '}'}).Count
$lines = (Get-Content "my_strategy_025.html.bak_$timestamp" | Measure-Object -Line).Lines
Write-Host "КОПИЯ: Строк: $lines | {: $o | }: $cl | Баланс: $(if($o -eq $cl){'✅'}else{'❌'})"
```

### Шаблон проверки последних 10 строк
```powershell
# PowerShell
$lastLines = Get-Content 'my_strategy_025.html' -Tail 10
$lastLines | ForEach-Object { Write-Host $_ }

# Ожидается:
# </script>
# </body>
# </html>
```

### Шаблон сообщения об усечении
```markdown
## ❌ Файл усечён

**Ожидалось:** 456 строк
**Фактически:** 443 строки

**Последние 10 строк:**
```
function boot(){
    // ...
    updateUI();
    addLog('v'+BOT_VERSION+' готов','info');
}

boot();
```

**Отсутствуют закрывающие теги:** `</script></body></html>`

**Действия:**
1. Восстановите файл из резервной копии
2. После восстановления сообщите мне — я проверю целостность
```
