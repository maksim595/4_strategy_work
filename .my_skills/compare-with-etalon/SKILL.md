# Compare with Etalon (Сравнение с эталоном)

**Когда использовать:** КАЖДАЯ правка, основанная на другом файле — исправление таймера, добавление функций, копирование логики из `fractal_bot_v0.7.1.html` или других файлов.

**Цель:** Предотвратить ошибки копирования — логика должна быть ТОЧНО как в эталоне.

---

## Пошаговая инструкция

### 1. ПОЛУЧЕНИЕ задачи на сравнение
- [ ] Определить эталонный файл (например, `fractal_bot_v0.7.1.html` для таймера)
- [ ] Прочитать ОБА файла (текущий и эталон) с `read_file` (limit=50-100)
- [ ] Найти точную логику в эталоне (`grep_search` по функции)

### 2. АНАЛИЗ эталона
- [ ] Выписать ключевые строки из эталона (дословно)
- [ ] Проверить контекст (что ДО и ПОСЛЕ ключевой логики)
- [ ] Убедиться, что в эталоне нет конфликтных функций

### 3. КОПИРОВАНИЕ логики
- [ ] Скопировать логику ТОЧНО (как в эталоне)
- [ ] Адаптировать имена переменных (если отличаются в текущем файле)
- [ ] Проверить, что логика НЕ пересекается с существующими функциями

### 4. ПРОВЕРКА после правки
- [ ] Сравнить с эталоном (ключевые строки должны совпадать)
- [ ] Проверить целостность файла (строки, скобки, `node -c`)
- [ ] Протестировать функцию (если применимо)

---

## Правила пользователя

1. **ВСЕГДА читать ОБА файла** — текущий И эталон
2. **Копировать ТОЧНО** — не изменять логику, только имена переменных
3. **Проверять контекст** — что ДО и ПОСЛЕ ключевой логики в эталоне
4. **Избегать конфликтов** — новая логика НЕ должна пересекаться с существующей
5. **Тестировать** — после копирования проверить, что функция работает

## Хорошие примеры

### ✅ Пример 1: Исправление таймера (2026-11-17)

**Задача:** Таймер «замирает» при загрузке — использовать логику из `fractal_bot_v0.7.1.html`

**Действия:**
1. Прочитан эталон (`fractal_bot_v0.7.1.html` строка 2903):
   ```javascript
   var startTime = Date.now();
   S.barTimerInterval = setInterval(function(){
       var elapsed = Date.now() - startTime;
       var remaining = tfMs - (elapsed % tfMs);
       // ...
   }, 1000);
   ```
2. Прочитан текущий файл (`my_strategy_025.html`):
   ```javascript
   // Было (сложная логика с lastBarTime):
   var lastBarTime = realTimeBars[...].timestamp;
   var elapsed = (now - lastBarTime) % tfMs;
   ```
3. Применена правка (точно как в эталоне):
   ```javascript
   var startTime = Date.now();
   function update() {
       var elapsed = Date.now() - startTime;
       var remaining = tfMs - (elapsed % tfMs);
   }
   ```
4. Проверка: 3199 строк, 1198/1198 скобок ✅

**Результат:** Таймер работает сразу при загрузке (как в v0.7.1).

## Плохой пример

### ❌ Пример: Частичное копирование таймера (2026-11-17)

**Задача:** Исправить таймер по аналогии с v0.7.1

**Что сделано НЕПРАВИЛЬНО:**
1. ❌ Прочитан ТОЛЬКО текущий файл (эталон НЕ прочитан)
2. ❌ Скопирована ЧАСТЬ логики (только `startTime`, но не `elapsed`)
3. ❌ НЕ проверен контекст в эталоне (что ПОСЛЕ `startTime`)
4. ❌ Файл усечён до 443 строк

**Симптом:** Таймер всё ещё «замирает»

**Причина:** Логика скопирована частично — `startTime` есть, но `elapsed` считается по-старому

**Как исправить:**
- ВСЕГДА читать ОБА файла (текущий И эталон)
- Копировать ВСЮ логику (не частично)
- Проверять контекст (что ДО и ПОСЛЕ)
