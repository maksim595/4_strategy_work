# Safe Edit (Безопасное редактирование HTML/JS)

**Когда использовать:** КАЖДОЕ редактирование HTML/JS файлов торгового бота — добавление функций, кнопок UI, исправление таймера, перемещение элементов.

**Цель:** Предотвратить повреждение файла: усечение `</script>`, разбаланс скобок `{}`, UTF-8 ошибки, синтаксические ошибки.

---

## Пошаговая инструкция

### 0. СРАВНЕНИЕ с эталоном (если применимо)
- [ ] Если правка основана на другом файле (например, `fractal_bot_v0.7.1.html`) — прочитать ОБА файла
- [ ] Найти точную логику в эталоне (`grep_search` по функции)
- [ ] Скопировать логику ТОЧНО (как в эталоне)
- [ ] Проверить, что в текущем файле нет конфликтных функций

### 1. ПЕРЕД правками
- [ ] Прочитать файл полностью (`read_file` с limit=50-100 для понимания контекста)
- [ ] Найти точное место вставки (`grep_search` по ID/функции)
- [ ] Скопировать `old_string` с запасом ±3 строки для уникальности

### 2. ПРОВЕРКА old_string
- [ ] Убедиться, что `old_string` встречается ТОЛЬКО 1 раз (`grep_search`)
- [ ] Проверить баланс `{}` в `old_string` (посчитать вручную)
- [ ] Проверить закрывающие теги `</script>`, `</div>`, `
